# 第六章：部署与运行

路线：[[Spring Boot工程实践学习路线]] · 前置：[[00-第五章-工程规范与质量]] · 通用基础：[[部署基础与请求链路]]。

## 本章目标与范围

理解 Spring Boot 从源码到运行服务的过程，知道产物怎样构建、配置怎样进入进程、流量怎样到达应用，以及发布失败、健康异常和资源紧张时怎样判断。继续使用订单应用，不把“JAR 上传了”“日志出现 Started”“接口返回了 200”中的任何一个，直接等同于整个业务上线成功。

本章为自读材料，尚未逐项讨论或实践。命令、配置与发布步骤均为教学示例，不是已经在本机或生产环境执行的操作。没有安装服务、修改系统配置、访问真实服务器或运行应用。前五章也不会因为阅读路线齐备而自动标为掌握。

## 本章贯穿的案例

订单应用准备发布新版本。构建与测试先核对应用行为，发布记录关联源码、产物、配置和数据变更；新实例启动后检查就绪与代表性接口，再按选定策略接入流量。旧实例退出前停止接收新工作，并处理进行中的请求和任务。若出现故障，先确认请求在哪一段失败，再决定修复、限制流量或回退。

这些步骤不要求学习项目一开始就上 Kubernetes 或复杂发布平台。单机 JAR 运行可以作为理解起点；多实例、容器、编排和自动发布是根据实际需求选择的实现方式。

## 完成阅读后仍需验证什么

真实可执行产物、目标 JDK 兼容、实际生效配置、测试资源隔离、代理后的真实路径、健康与业务检查、停止信号和时间预算，以及数据库变更后的回退条件，都需要在选定项目与环境中验证。
