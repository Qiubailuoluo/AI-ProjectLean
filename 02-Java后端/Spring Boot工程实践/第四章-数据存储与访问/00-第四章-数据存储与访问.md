## 复习时特别注意

- 其他索引不是聚簇索引的子树；回表访问的是同一张表的聚簇索引，不是查别的表。
- 用户只是简单了解 B+ 树，不能以听过术语为由跳过基础。
- 校验、事务、并发保障和索引各有职责，不能互相替代。
- 所有 SQL 都是教学示例，未连接真实业务数据库或进行性能实验。
