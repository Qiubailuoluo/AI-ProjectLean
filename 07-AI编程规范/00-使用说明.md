# 使用说明

版本：0.50 · 更新：2026-11-01

## 分发与接手

1. 把整个 `07-AI编程规范/` 文件夹压缩发给对方。
2. 对方解压后，在 AI 对话里说：

   > 读取 `07-AI编程规范/README.md`，按“给接手的 AI”一节，把 Skill 安装到当前项目，并告诉我做了什么。

3. 也可以手动安装：

```sh
python3 07-AI编程规范/tools/install.py <项目路径>                  # Cursor → <项目>/.cursor/skills/
python3 07-AI编程规范/tools/install.py <项目路径> --target claude  # Claude Code → <项目>/.claude/skills/
python3 07-AI编程规范/tools/install.py <项目路径> --dry-run        # 先预览
```

- 项目级安装。装完后，项目里只多出 `skills/` 下的内容，`maintenance/`、`templates/`、`tools/` 不会进入项目。
- 必须整套安装。已有同名 Skill 默认跳过，确认要覆盖再加 `--force`。
- 装完新开一个对话，让 AI 做个小任务，看回复末尾是否有“读取的规范 / 已验证 / 未验证”。没有，说明没触发，检查安装位置和 `description`。

## 不支持 Skill 的工具

| 工具 | 做法 |
| --- | --- |
| Codex 等仓库型工具 | 把本文件夹放进仓库，用 [`templates/AGENTS.md`](templates/AGENTS.md) 让 AI 按任务读 `skills/*/SKILL.md` |
| Cursor 想强化触发 | 加 [`templates/cursor-rule.mdc`](templates/cursor-rule.mdc)，复制为 `.cursor/rules/ai-coding-standards.mdc`；原生 Skill 能自动触发时可不加 |
| ChatGPT Projects、DeepSeek 等只能收附件的 | 附上 `engineering-baseline/SKILL.md`、匹配的 Skill 及需要的 reference |

能否自动发现 Skill 由客户端决定，与模型名称无关。首次接入后，核对 AI 实际读取了哪些文件。

## 日常维护

```sh
python3 tools/check.py
```

检查 `name` 与目录名、`description`、`SKILL.md` 行数、所有链接和标题锚点、孤立文件，并报告常驻上下文成本。修改流程见[扩展指南](maintenance/扩展指南.md)；改动记入 [CHANGELOG](maintenance/CHANGELOG.md)，待办记入 [issues](maintenance/issues.md)，较大改动后用[回归任务](maintenance/regression-tasks.md)验证。
