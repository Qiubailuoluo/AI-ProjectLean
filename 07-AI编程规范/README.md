# AI 编程规范

按任务路由加载适用 Skill 及其引用资料。规范适用范围由用户需求和目标仓库确定；示例不构成项目事实。

## 任务路由

| 任务 | 入口 |
| --- | --- |
| 审查代码差异、提交或 PR，检查安全、正确性、并发或性能风险 | [代码审查 Skill](common/skills/code-review/SKILL.md) |
| Spring Boot API、Service、MyBatis/XML、持久化、事务、项目配置、测试或发布 | [Spring Boot 路由](springboot-change/README.md) |
| MySQL 表结构、索引、查询调优、测试、迁移、安全、备份或版本升级 | [MySQL Skill](mysql/SKILL.md) |
| Redis 缓存结构与键值设计、读写一致性、失效或降级 | [Redis Skill](redis/SKILL.md) |
| MinIO 文件上传、访问、业务绑定或回收 | [MinIO Skill](minio/SKILL.md) |
| Nginx 代理路径、请求头、上传限制、代理缓存、超时或上游排查 | [Nginx Skill](nginx/SKILL.md) |

Spring Boot 集成任务按实际技术组合入口：使用 MySQL 的持久化变更加 MySQL，使用 Redis 的缓存变更加 Redis。Spring Boot 项目中的 Spring Cache 或本地缓存经 Service 入口读取框架缓存参考；单独修改缓存配置也可经项目配置入口读取。

## 加载约定

- 依据本次修改的行为选择入口；引用链接仅在其适用条件成立时继续读取，不递归遍历全部资料。
- 仅核实影响当前决策的环境信息。同一任务中已读取且未变化的资料直接复用；信息足以实施和验证时停止扩展读取。
- 本规范补充用户要求和目标仓库约定，不替代实际代码、配置及版本证据。未覆盖的技术任务依据目标项目与官方资料处理，不强行套用相近 Skill。
- 应用条款前核对适用条件、已有实现和预期行为；发现冲突、过时内容或证据不足时，按[规范适用性核查](common/references/工程底线.md#规范适用性核查)处理。遵循 Skill 不构成实现正确的证据。
- 示例仅在需要具体时序、实现片段或验证方法时加载。单个 Skill 的文件长度不代表一次任务的总上下文开销。

## 共用规则

- 跨技术域代码审查：[代码审查 Skill](common/skills/code-review/SKILL.md)。
- [工程底线](common/references/工程底线.md)：身份、数据归属、失败语义、敏感信息及验证边界。
- [代码复用与注释](common/references/代码复用与注释.md)：实现前核查、共享能力边界和注释要求。
- 目录、依赖、数据库版本、部署方式及业务名称以目标仓库和环境为准；不得从规范示例推定项目需求。

工具接入说明见[00-使用说明](00-使用说明.md)。复制时保留完整 `07-AI编程规范/` 目录及相对路径，以维持跨域引用解析。

仅在编写、修改或审查本规范时，读取[Skill 编写与审查复盘](01-Skill编写与审查复盘.md)；普通编码任务不加载该维护文档。
