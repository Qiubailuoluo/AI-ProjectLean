# AI 编程规范

面向不同业务项目，按任务路由加载适用 Skill 及其引用资料。业务范围由用户需求和目标仓库确定；订单、商品、库存等仅为机制示例，不定义目标项目的模块、字段、流程或技术选型。

## 任务路由

| 任务 | 入口 |
| --- | --- |
| 审查代码差异、提交或 PR，检查安全、正确性、并发或性能风险 | [代码审查 Skill](common/skills/code-review/SKILL.md) |
| 新功能分支隔离、Git 提交/推送、PR/MR 或变更描述 | [Git 交付 Skill](common/skills/git-delivery/SKILL.md) |
| 项目记录、跨会话恢复、多 AI 文档归属或临时资料整理 | [项目记录 Skill](common/skills/project-memory/SKILL.md) |
| Spring Boot API、Service、MyBatis/XML、持久化、事务、项目配置、测试或发布 | [Spring Boot 路由](springboot-change/README.md) |
| Vue 页面、组件、接口状态、视觉体系、多语言、系统偏好、路由会话、构建或前端测试 | [Vue 路由](vue/README.md) |
| MySQL 表结构、索引、查询调优、测试、迁移、安全、备份或版本升级 | [MySQL Skill](mysql/SKILL.md) |
| Redis 缓存结构与键值设计、客户端连接/命令资源、读写一致性、失效或降级 | [Redis Skill](redis/SKILL.md) |
| MinIO 文件上传、访问、业务绑定或回收 | [MinIO Skill](minio/SKILL.md) |
| Nginx 代理路径、请求头、上传限制、限流并发、代理缓存、超时或上游排查 | [Nginx Skill](nginx/SKILL.md) |

Spring Boot 集成任务按实际技术组合入口：使用 MySQL 的持久化变更加 MySQL，使用 Redis 的缓存变更加 Redis。Spring Boot 项目中的 Spring Cache 或本地缓存经 Service 入口读取框架缓存参考；单独修改缓存配置也可经项目配置入口读取。

前后端联动任务按实际改动组合 Vue、Spring Boot 与中间件入口。分别核对接口字段、认证、错误语义、上传流程和部署路径；不从任一侧的类型或 Mock 推定另一侧的实际行为。

涉及公开高成本接口、限流或人机验证时，按需读取[请求防滥用与资源边界](common/references/请求防滥用与资源边界.md)；涉及管理员下载包、用户附件、资源发布或上传下载安全时，读取[资源发布与上传下载](common/references/资源发布与上传下载.md)。按实际技术继续组合入口，不假定使用 MinIO 或 Nginx。

新功能实施前按[Git 交付 Skill](common/skills/git-delivery/SKILL.md)核对任务分支及项目流程；已有任务分支直接复用。只读咨询与审查不创建分支，编码授权不自动扩大为推送、合并或发布。

目标业务项目已有记录入口时，新会话先读短索引及本任务记录；初始化、整理或交接时再加载[项目记录 Skill](common/skills/project-memory/SKILL.md)。涉及根目录、环境文件或部署目录整理时，读取[项目目录与部署边界](common/references/项目目录与部署边界.md)；不自动重组目标仓库。

本地启动、调试或提交前涉及个人适配时，按需读取[本地运行配置与提交隔离](common/references/本地运行配置与提交隔离.md)，标明仅本地改动并核对暂存与交付内容。

## 加载约定

- 依据本次修改的行为选择入口；引用链接仅在其适用条件成立时继续读取，不递归遍历全部资料。
- 仅核实影响当前决策的环境信息。同一任务中已读取且未变化的资料直接复用；信息足以实施和验证时停止扩展读取。
- 本规范补充用户要求和目标仓库约定，不替代实际代码、配置及版本证据。未覆盖的技术任务依据目标项目与官方资料处理，不强行套用相近 Skill。
- 应用条款前核对适用条件、已有实现和预期行为；发现冲突、过时内容或证据不足时，按[规范适用性核查](common/references/工程底线.md#规范适用性核查)处理。遵循 Skill 不构成实现正确的证据。
- 示例仅在需要具体时序、实现片段或验证方法时加载。先核对其不变量、权限、事务和失败前提，仅迁移适用机制；实现及交付文档使用目标项目术语，不照搬示例业务。单个 Skill 的文件长度不代表一次任务的总上下文开销。

## 共用规则

- 跨技术域代码审查：[代码审查 Skill](common/skills/code-review/SKILL.md)。
- [工程底线](common/references/工程底线.md)：身份、数据归属、失败语义、敏感信息及验证边界。
- [代码复用与注释](common/references/代码复用与注释.md)：实现前核查、共享能力边界和注释要求。
- 目录、依赖、数据库版本与部署方式以目标仓库和环境为准。

工具接入说明见[00-使用说明](00-使用说明.md)。复制时保留完整 `07-AI编程规范/` 目录及相对路径，以维持跨域引用解析。

本规范的维护记录见[维护入口](maintenance/README.md)，不纳入普通编码或新会话的默认上下文。发现问题、提出优化或评审本规范时才进入；新增记录仅查相关议题，综合复审时再梳理全部维护记录。
