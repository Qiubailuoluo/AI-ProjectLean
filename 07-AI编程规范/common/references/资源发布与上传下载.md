# 资源发布与上传下载

适用范围：管理员发布下载包、用户附件、文件上传确认、下载授权及资源存储。按实际采用的受控文件服务、对象存储或 CDN 实施，不要求迁移到特定产品。

## 存储与发布边界

- 与前端版本无强耦合的压缩包、安装包和用户文件，默认存放于前端发布目录以外的受控文件目录或对象存储，不纳入前端源码、`public/` 或发布产物；可复用既有文件服务，不要求另建进程。界面所需图标、字体及明确的离线交付资源按需求保留；已有资源迁移先核对调用方和历史链接，不直接删除。
- 管理员上传同样经过服务端认证、发布权限和内容/大小校验；区分上传、待校验、发布、下架及删除等业务状态。状态名和审批机制按项目需要确定，不能因上传者是管理员而默认文件可信。
- 业务记录保存稳定资源标识、归属、版本、状态及所需大小/摘要等元数据；不将临时签名 URL 作为永久地址。公开资源与用户私有附件分别定义可见性，用户原文件名不作为存储路径或授权凭证。
- 下载地址由受控配置和服务端资源记录解析，不信任客户端传入的磁盘路径、对象 Key 或任意远程地址。磁盘服务须规范化并校验路径位于受控根目录，处理符号链接逃逸，不将原始用户路径直接拼接后读取。服务端拉取远程资源时需单独约束目标及重定向，防止 SSRF；无需求时不新增远程抓取能力。

## 上传校验与隔离

- 使用 Cookie 等浏览器自动携带的凭据时，上传、确认、发布和删除入口执行[工程底线](工程底线.md#通用要求)中的 CSRF 要求。
- 前端按契约预检格式、数量和大小并反馈，后端及实际存储入口独立执行限制。直传绕过代理时仍需约束实际存储写入；签发前校验权限和配额，确认前复核实际对象，超限或未确认对象不得发布，并应有回收路径。确认时校验不能阻止此前的存储占用；按目标能力核实签名策略、并发配额预留和上传字节限制，无法在直传入口实施必要硬限制时选择受控上传路径。
- 服务端依据允许用途校验扩展名、实际格式、大小及必要的内容特征，不能仅相信 `Content-Type`、客户端摘要或文件名。拒绝不支持的格式；加密归档等无法完成所需检查的内容须有明确拒绝或隔离规则。
- 使用服务端生成的对象标识或路径，隔离用户/租户及暂存/已发布内容。文件放在不可执行的位置并使用最小权限；未通过所需检查不得通过公开路径读取或被后台自动处理。检测器或处理库故障不能直接视为通过。
- 仅存储并下载的压缩包无需为校验而默认完整解压。确需解压、预览或扫描时，限制实际解压字节数、条目数、压缩比、嵌套深度及处理时间，检查规范化路径、绝对路径、`..` 和符号链接，避免路径穿越及解压炸弹。处理库保持受支持版本，使用受限临时空间并清理失败产物；按风险复用恶意内容扫描能力。
- 上传凭据、完成确认和最终业务引用必须指向同一已验证内容，避免校验后被覆盖。对象存储的版本绑定、部分失败及回收细节，仅在实际使用 MinIO/S3 兼容服务时读取[文件生命周期](../../minio/references/文件生命周期.md)。

## 下载、撤销与运维

- 私有文件每次签发或代理下载前检查资源归属与访问权限；公开文件也须核对已发布状态。短期签名凭据不保证立即撤销；要求立即下架的内容须选择能在访问时强制检查状态的机制，并处理缓存副本。
- 用户主动下载使用原生下载入口或项目已有能力；大文件优先由受控文件服务流式交付，不为下载默认完整载入浏览器或应用内存。需要鉴权请求时沿用实际契约，第三方下载不得误带业务令牌。
- 下载响应按实际内容设置类型与安全的文件名；不信任上传者控制的响应头。非可信 HTML/SVG 等主动内容按风险隔离来源或强制附件下载，并防止类型嗅探；私有响应的缓存授权覆盖命中路径。
- 对高成本上传、签名签发、下载及 Range 请求考虑频率、并发、流量和配额，不能只限制获取下载地址的接口。入口和应用约束见[请求防滥用与资源边界](请求防滥用与资源边界.md)。
- 发布前核对磁盘/对象容量、暂存清理、失败重试和可恢复备份；资源替换保留版本与引用关系，避免新版本上传失败破坏旧版。按需求记录脱敏的发布、下载授权、下架和删除审计。

## 验证

按变更范围验证未授权上传/下载、跨用户或租户访问、伪造类型、超限、并发配额、校验失败后访问、重复确认、替换失败及下架后的访问。确有解压流程时验证路径穿越与受控的解压超限样例。跨层任务核对前端、后端、实际代理及存储入口，不能仅验证前端拦截。

参考：[OWASP 文件上传](https://cheatsheetseries.owasp.org/cheatsheets/File_Upload_Cheat_Sheet.html)、[Vite 静态资源与 public](https://vite.dev/guide/assets.html#the-public-directory)。Vite 产物规则仅在使用 Vite 时适用。
