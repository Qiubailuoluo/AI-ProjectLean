# 项目记录与交接

先定位项目已有记录入口、当前任务及写入归属。记录帮助定位实现，不替代代码、测试和当前授权；不为简单咨询默认初始化整套文档。

- 初始化记录、恢复任务、维护需求/Bug/决策或多 AI 协作时，读取[项目记录与多 AI 协作](../../references/项目记录与多AI协作.md)。
- 整理外部临时资料或准备清理资料目录时，读取[临时资料整理与归档](../../references/临时资料整理与归档.md)。

仅写入自己的记录目录或被明确指定维护的共享文件；其他 AI 的目录只读。交付简述记录位置、已核实事项及仍待核实的冲突，不把其他 AI 的结论或历史计划当作当前事实与授权。
