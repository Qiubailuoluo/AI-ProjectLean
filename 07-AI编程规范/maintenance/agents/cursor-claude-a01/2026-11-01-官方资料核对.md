## 已核对，无需修改

- Java：`Executors.newFixedThreadPool` 使用无界队列（Oracle Javadoc）。
- Redis：`SCAN` 只提供有限保证、会遍历期间变化；`KEYS` 在大库会长时间阻塞（redis.io）。
- Spring Cache：抽象不处理多线程多进程；无锁，多线程可能同时装载；多节点需自行配置传播（Spring 官方 Cache Abstraction）。

- Nginx：`limit_conn` 空键不计数、默认 503、HTTP/2·3 按并发请求计数；`proxy_ssl_verify` 默认 off；`proxy_read_timeout` 是相邻两次读取之间的时间；`proxy_cache_bypass` 与 `proxy_no_cache` 分别控制读与写；`non_idempotent` 重试选项存在。来源：nginx.org 的 limit_conn 与 proxy 模块文档。
- MySQL：死锁回滚整个事务；锁等待超时默认只回滚当前语句，`innodb_rollback_on_timeout` 开启后回滚整个事务；`EXPLAIN ANALYZE` 会真正执行语句。来源：MySQL 8.4 手册。
- S3/MinIO：预签名 URL 到期前可重复使用，同 Key 的 PUT 会覆盖，URL 等同 bearer 凭据。来源：AWS S3 预签名文档。
- Compose：`depends_on.condition: service_healthy` 的语义与示例写法。
