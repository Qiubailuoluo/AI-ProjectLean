# Redis 工程规范

变更前界定 Redis 职责、权威数据源、允许陈旧范围、客户端/服务端版本及故障策略。

## 阅读

- 选择 Redis 结构、缓存范围、Key 命名、Value 投影、序列化或 TTL：[数据结构与键值设计](references/数据结构与键值设计.md)。
- 缓存键、读写、失效时序、一致性及故障降级：[缓存读写与一致性](references/缓存读写与一致性.md)。
- 需要具体时序分析失效恢复或旧值回填竞态时，读[缓存失效与恢复](examples/缓存失效与恢复.md)。
- 新增或修改实现代码时，读取[代码复用与注释](../common/references/代码复用与注释.md)；涉及业务权限或敏感数据时，读取[通用工程底线](../common/references/工程底线.md)。

验证本次变更涉及的命中、未命中、过期、并发更新、失效失败及 Redis 不可用路径。缓存不替代权威数据的业务约束。
