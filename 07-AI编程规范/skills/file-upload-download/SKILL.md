# 文件上传、下载与资源发布

先确认项目实际使用的存储（本地受控目录、MinIO/S3、CDN）。不要求迁移到特定产品。

## 核心规则

- 下载包、安装包、用户文件不放进前端源码、`public/` 或构建产物，放在受控目录或对象存储。
- 管理员上传也要认证、校验权限、内容和大小。管理员身份不代表文件可信。
- 业务记录存稳定的资源 ID、归属、状态、大小或摘要。不把临时签名 URL 当永久地址，不用用户原文件名当存储路径。
- 下载地址由服务端按资源记录解析，不信任客户端传来的磁盘路径、对象 Key、远程地址。
- 类型校验看实际内容，不信 `Content-Type`、扩展名、客户端摘要。
- 校验通过前，文件不能被公开路径读取，也不能被后台自动处理。检测组件故障按失败处理。
- 私有文件每次下载前检查归属与权限。签名链接到期前无法撤销，需要立即下架的内容要在访问时检查状态。
- 浏览器自动携带 Cookie 时，上传、确认、发布、删除接口要有 CSRF 防护。

## 验证

覆盖未授权访问、跨用户或跨租户访问、伪造类型、超限、校验失败后访问、重复确认、下架后访问。要在前端、后端、实际代理和存储入口各验一次，不能只验前端拦截。
