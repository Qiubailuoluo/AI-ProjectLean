# 下载与访问控制

适用：MinIO 或 S3 兼容存储中，私有对象的读取、预签名下载。

## 规则

- 私有对象默认保持私有。每次访问，先按业务资源检查用户或租户权限，再二选一：
  - 后端转发对象流；
  - 签发短期、限定对象和操作的下载凭据。
- 预签名 URL 谁拿到谁能用，要当凭据对待：
  - 有效期短、权限最小；
  - 不写进日志、工单、分析事件；
  - 不出现在可被第三方读取的页面引用里。
- 响应类型、下载文件名、是否内联展示，按内容风险设置。不用客户端提供的元数据做安全决策。主动内容要隔离，或强制下载。
- 私有内容经 Nginx 缓存时，授权和有效期检查要覆盖缓存命中的路径，见[代理缓存](../../nginx-proxy/references/代理缓存.md)。

## 验证

覆盖：私有对象越权访问、预签名到期后的访问、缓存命中时的授权检查。
