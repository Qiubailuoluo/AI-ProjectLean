# MySQL 工程规范

版本相关行为以目标版本文档和实际配置为准。

## 核心规则

- 先确认服务器版本、字符集与排序规则、SQL mode 和迁移工具。
- DDL 通过版本化迁移脚本执行，不手改线上表；大表变更先评估锁和耗时。
- 主键、非空、唯一、引用完整性在库内用约束兜底。
- 索引按实际查询模式设计，并用 `EXPLAIN` 验证；避免在索引列上做函数或隐式类型转换。
- 金额用 `DECIMAL`；字符集用 `utf8mb4`；时间字段统一时区策略。
- 应用账号最小权限；备份必须做过恢复演练才算有效。
