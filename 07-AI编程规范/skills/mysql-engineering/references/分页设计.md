# MySQL 分页设计

适用：列表分页、游标分页、持续加载、深分页。索引与执行计划见[索引设计与执行计划](索引设计与执行计划.md)。

## 选型

- 需要任意跳页：评估页码分页。
- 持续加载或深位置查询：评估游标分页。
- 选择依据：查询成本、接口语义、数据变化的要求。

## 排序

- 分页结果要有确定的排序。排序值可能重复时，追加唯一字段作为稳定排序键。
- 深 OFFSET 会扫描并丢弃大量记录。返回行数，不代表实际扫描量。

## 游标

- 继续条件要覆盖：全部排序字段、方向、唯一的补序字段。
- 用 `pageSize + 1` 判断 `hasMore` 时，下一个游标取"最后一条实际返回的记录"，不取探测行。
- 游标不提供数据库快照，也不做权限校验。
- 明确分页期间新增、删除、排序字段变化时，数据的可见性。严格的导出或一致性快照，另行设计。
