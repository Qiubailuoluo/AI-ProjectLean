# Nginx 超时、重试与请求体

适用：代理超时、上游重试、上传大小限制、WebSocket、SSE、流式响应、大文件。指令行为以目标 Nginx 版本和生效配置为准。

## 超时

- 分别设置：连接、请求发送、上游响应读取、客户端超时。与应用、数据库、外部依赖的超时预算协调。
- `proxy_read_timeout` 等读取超时，表示"相邻两次读操作的间隔"，不是整个响应的总时长上限。

## 重试

- `proxy_next_upstream` 会在配置的条件下，把请求转发给其他上游。
- 非幂等请求，在请求已发送之后重试，要单独审查。未确认幂等性，就不要启用这类重试。

## 请求体与上传限制

- 上传限制按实际流量路径，在 Nginx、应用、存储侧协调设置，核对各层的能力和限制。直传大小策略和确认边界，使用 `file-upload-download`。
- `client_max_body_size` 超限时，代理层返回 413。请求缓冲可能占用内存或临时磁盘。
- 直传 MinIO 时，确认流量是否经过 Nginx。

## 流式与长连接

WebSocket、SSE、流式响应、大文件传输，要单独核对：协议升级、缓冲、连接时长、资源限制。普通 JSON 代理的配置，覆盖不了这些场景的专用要求。

官方参考：[代理模块](https://nginx.org/en/docs/http/ngx_http_proxy_module.html)。
