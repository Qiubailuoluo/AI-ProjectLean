# Nginx 转发头与信任边界

适用：`Host`、`X-Forwarded-*`、`Forwarded`、客户端真实地址、HTTPS 上游。指令行为以目标 Nginx 版本和生效配置为准。

## 转发头

- `Host`、`X-Forwarded-For`、`X-Forwarded-Proto`、`Forwarded` 传给上游的值，按部署拓扑定义。
- 不直接信任公网请求自带的身份、客户端地址、协议声明。
- 明确哪些代理地址可信。在边界处配置覆盖、追加、解析规则。应用只信任来自已配置代理链的转发信息。
- 代理头不承担业务认证和资源授权。
- `Host` 会影响绝对链接、租户路由、签名校验。按允许的主机名配置虚拟主机和上游值，不把任意请求头用于安全决策。

## HTTPS 上游

- 核验可信 CA、证书链、目标名。配置 `proxy_ssl_verify`、`proxy_ssl_trusted_certificate`，适用时配置 `proxy_ssl_name`。需要 SNI 时，启用 `proxy_ssl_server_name`。
- `proxy_pass https://...` 本身不会启用证书校验。
- 验证：正确的证书可用，错误的证书被拒绝。

官方参考：[代理模块](https://nginx.org/en/docs/http/ngx_http_proxy_module.html)。
