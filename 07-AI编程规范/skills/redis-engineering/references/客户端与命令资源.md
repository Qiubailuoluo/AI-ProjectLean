# Redis 缓存客户端与命令资源

适用范围：可重建缓存客户端、连接预算、命令批处理、扫描清理及安全连接。以实际客户端版本和连接模型为准。

- 复用项目已有客户端生命周期，核对连接建立、命令执行、连接池等待及重连预算；请求结束不关闭应用共享客户端。流水线、事务、订阅及阻塞命令是否需要专用连接依据实际客户端规则判断，不把缓存连接模型直接套用其他职责。
- 批量操作限制命令数和返回字节数；Pipeline 减少往返但不自动提供原子性。Lua/函数和大集合操作须有执行成本边界，避免长时间阻塞其他请求。`SCAN` 不是一致性快照，遍历可能重复或受并发变化影响，清理任务需幂等并限定命名空间。
- 连接失败、命令超时和写入结果未知分别处理，重连及重试须有限并避免同步风暴。部署安全核对访问网络、ACL/凭据和跨非可信网络的传输保护；缓存服务不得直接无认证暴露公网。


## 验证

按改动验证连接复用、超时和断线重连、批次与返回量上限、扫描重复处理及清理范围；凭据或网络策略变更核验拒绝路径。缓存失效或回源策略本身变化时，再读[缓存读写与一致性](缓存读写与一致性.md)。

参考：[Redis Pipeline](https://redis.io/docs/latest/develop/using-commands/pipelining/)、[SCAN 遍历保证](https://redis.io/docs/latest/commands/scan/)。
