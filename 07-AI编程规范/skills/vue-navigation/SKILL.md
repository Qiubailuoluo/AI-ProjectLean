# Vue 路由与会话

改动前先确认 Router 版本、现有路由表、认证流程、后端权限契约和部署路径。

## 核心规则

- 路由守卫只改善体验，权限最终由后端接口判定。
- 登录态在刷新、过期、退出、多标签页下的行为要明确；退出时清理会话数据并终止在途请求。
- 登录后的跳转目标须校验为站内路径，防开放重定向。
- 导航失败、404、无权限要有明确的落点页面。
- 部署子路径与路由模式（history/hash）要匹配，刷新直达必须可访问。

## 按需读取

- 路由、登录态、导航守卫、页面权限：[路由与会话](references/路由与会话.md)
- 登录或刷新涉及接口：同时使用 `vue-data`
- 部署路径变化：同时使用 `vue-tooling`

## 验证

直接访问、刷新、过期、退出、越权、导航失败这几条路径。
