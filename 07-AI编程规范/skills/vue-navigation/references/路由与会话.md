# Vue 路由、会话与页面访问

适用：路由表、导航守卫、登录恢复、菜单、退出、页面权限。Router 版本和导航 API 以项目依赖为准。

## 授权边界

- 路由元数据和菜单，控制的是页面体验，不是后端资源授权。
- 服务端要基于可信身份，核验受保护的操作。前端隐藏入口，不能证明请求无权访问。

## 导航守卫

- 区分四种状态：未登录、会话待恢复、已登录但无权、系统故障。
- 避免：循环重定向、重复请求、刷新后短暂展示受限页面。
- 过期恢复失败时，不要无限重试。

## 登录与退出

- 登录后的返回地址，默认限定为应用内的可信目标。
- 跨站单点登录等已确认的流程，依据受控目标的白名单校验。不直接采用用户提供的任意地址。
- 退出或身份切换时，清理相关的请求、页面、共享状态。同时使用 `vue-data`，读「请求与状态」和「共享状态与缓存」，阻止旧会话的回调写入。
- 授权信息变化时，核查已打开的页面和共享缓存里可见的状态。

## 错误与参数

- 401、403、404、网络失败，各自依据后端契约处理。
- 路由参数是外部输入。详情页要处理：资源不存在、已删除、越权、直接访问。路由参数存在，不代表资源可访问。

## 部署

使用 History 模式和非根路径部署时，构建的 `base`、路由基础路径、静态服务的回退，必须一致。静态资源请求和 API 请求，不能被无条件回退到应用入口。

## 验证

- 验证：直接访问、刷新、返回、登录过期、越权、切换用户、无效的目标 URL。
- 涉及代理路径时，使用 `nginx-proxy`。同时核对后端真实的权限边界。
