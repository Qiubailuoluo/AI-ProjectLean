# Vue 构建与验证

改动前先确认项目版本、包管理器、锁文件、脚本、构建工具、路由模式和目标环境。

## 核心规则

- 使用项目锁定的包管理器和锁文件，不混用 npm、yarn、pnpm。
- 依赖升级只做任务所需，并提交锁文件变更。
- 构建工具暴露给浏览器的环境变量（如 Vite 的 `VITE_` 前缀）会进入前端包，不得放密钥。
- 构建与部署路径（base、代理、静态资源路径）要实测。
- lint 与类型检查、构建、测试、真实部署分别报告；未执行的不得写成通过。

## 按需读取

- 依赖、构建配置、资源发布、部署路径：[构建与验证](references/构建与验证.md)
- 浏览器流程测试：读 `vue-ui`「页面可操作性与自动化验证」
- 下载包、附件、发布产物的体积：同时使用 `file-upload-download`
- 根目录、环境文件、Docker/Compose、部署目录：读 `deploy-layout`「项目目录与文件归属」
- 生产环境用 Nginx 提供静态资源或代理：同时使用 `nginx-proxy`；用其他托管方式时，依据对应平台配置

## 验证

用项目实际命令验证受影响的构建和运行行为。静态检查、构建、测试、真实部署分别报告。
