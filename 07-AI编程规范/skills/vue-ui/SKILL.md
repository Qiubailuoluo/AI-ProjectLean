# Vue 页面与组件

改动前先看现有组件、设计系统、页面调用方和项目的 Vue 版本。

## 核心规则

- 沿用项目已有组件库和设计令牌；未经同意不引入新的 UI 库。
- 同一业务字段在各页面的展示名和格式保持一致；重复的组件和样式抽取到共享位置。
- 每个异步交互覆盖加载、空、失败、成功四种状态，并防止重复提交。
- 前端校验只为体验，服务端校验不可省；前端隐藏不等于授权。
- 表单和交互元素可用键盘操作，并有可定位的标识（label、aria、测试属性）。
- 长页面按职责拆分，不在同一文件里无限追加。

## 按需读取

- 组件、表单、字段展示、渲染、无障碍：[页面与组件](references/页面与组件.md)

## 验证

按受影响的交互核对输入、加载、失败、成功状态。不要从示例推断项目用什么组件库或代码风格。
