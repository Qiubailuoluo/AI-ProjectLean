# Vue 国际化与平台适配

适用：语言切换、区域格式、明暗主题、系统偏好、跨操作系统交互。支持范围以产品目标和现有部署环境为准。单语言项目，不因本文强制引入国际化依赖。

## 多语言

- 核对：现有的国际化实现、目标语言、默认语言、缺失翻译的回退。
- 新文案、表单错误、按钮、导航、空状态，使用同一个消息来源。
- 业务含义稳定的字段标签，在适当范围内复用。页面语义不同，可以分别翻译。
- 不通过拼接翻译片段来构造句子。
- 后端返回的错误码、枚举、内容是否要本地化，依据接口契约处理。

## 区域格式

- 数量、日期、时间、货币、数字，使用目标区域的格式。
- 展示格式和传输值分别处理。语言切换，不能改变币种、金额、日期的含义。
- 区分纯日期和时间点。时区按业务契约确定。
- 超过 JavaScript 安全整数范围的标识符，和高精度金额，按契约用无损表示。不要为了格式化，先转成有损的 `Number`。

## 切换与布局

- 语言切换时，核对：当前页面、已打开的弹窗、组件库内置文案、持久化偏好，是否同步。
- 预留文本长度的变化。产品实际支持从右到左的语言时，再验证布局方向和图标语义。

## 系统外观

- 产品提供"跟随系统 / 浅色 / 深色"时，明确：用户手动选择和系统偏好谁优先，偏好是否保存。
- 跟随系统时，响应系统外观的变化，避免首次渲染和实际主题短暂不一致。
- 主题切换用项目既有的变量和组件库的主题能力，覆盖：背景、文字、边框、焦点、图标、弹窗。检查对比度。
- 系统的"减少动态效果"偏好，独立于明暗主题。适用时，降低或关闭非必要的动画。

## 平台差异

- 按产品的支持矩阵，核对目标浏览器和 Windows、macOS、Linux 上的：字体回退、键盘快捷键、触控和鼠标交互、滚动条、文件选择体验。
- 依赖具体平台 API 时，做能力检测或适当退化。不按操作系统名称复制整套页面。

## 验证

- 按目标支持范围检查：语言切换与回退、数字日期格式、长文案、组件库内置文案、系统主题变化、手动覆盖、减少动画偏好。
- 跨平台问题，以可复现的设备、浏览器版本、操作路径记录。没实测的平台，不报告为已适配。
