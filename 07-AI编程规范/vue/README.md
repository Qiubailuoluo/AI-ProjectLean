# Vue 编程规范

按当前任务选择入口。仅在影响当前决策时核实相关 Vue、Router、状态管理、构建工具或组件库版本；以下资料不要求引入特定依赖或改造既有目录。

| 任务 | Skill |
| --- | --- |
| 页面、组件、工程组织、表单、视觉体系、多语言、系统外观或 AI 可操作性 | [vue-ui](skills/vue-ui/SKILL.md) |
| 请求封装、接口数据、共享状态、客户端缓存、文件上传下载或限流反馈 | [vue-data](skills/vue-data/SKILL.md) |
| 路由、登录态、导航守卫或页面权限 | [vue-navigation](skills/vue-navigation/SKILL.md) |
| 依赖、构建配置、资源发布、部署路径或专项测试 | [vue-tooling](skills/vue-tooling/SKILL.md) |

跨职责任务组合对应入口。例如登录页涉及页面、请求与导航；文件上传涉及请求、表单和实际对象存储流程。组件复用、样式统一或长页面整理经 `vue-ui` 按需读取页面组织参考；视觉体系、国际化与系统偏好分别读取对应专题。仅读取相关参考，验证当前项目的接口与运行行为。[总路由](../README.md)与[规范适用性核查](../common/references/工程底线.md#规范适用性核查)适用于本目录。
