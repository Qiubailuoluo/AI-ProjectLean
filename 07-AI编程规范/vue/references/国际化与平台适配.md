# Vue 国际化与平台适配

适用范围：语言切换、区域格式、明暗主题、系统偏好或跨操作系统交互。支持范围以产品目标与现有部署环境为准；单语言项目不因本参考强制引入国际化依赖。

## 多语言与区域

- 核对现有国际化实现、目标语言、默认语言和缺失翻译回退。新文案、表单错误、按钮、导航与空状态使用同一消息来源；稳定业务含义的字段标签在适当范围复用，页面语义不同可分别翻译。
- 不通过拼接翻译片段构造句子；数量、日期、时间、货币和数字使用目标区域格式。后端返回的错误码、枚举及内容是否需要本地化，依据接口契约处理。
- 展示格式与传输值分别处理。语言切换不改变币种、金额或日期含义；区分纯日期和时间点，时区按业务契约确定。超过 JavaScript 安全整数范围的标识符及高精度金额按契约使用无损表示，不为格式化先转换为有损 `Number`。
- 语言切换时核对当前页面、已打开弹窗、组件库内置文案和持久化偏好的同步。预留文本长度变化；产品实际支持从右到左语言时，再验证布局方向和图标语义。

## 系统外观与输入差异

- 若产品提供“跟随系统 / 浅色 / 深色”选择，明确用户手动选择与系统偏好的优先级，以及偏好是否保存。跟随系统时响应系统外观变化，避免首次渲染与实际主题短暂不一致。
- 主题切换通过项目既有变量与组件库主题能力覆盖背景、文字、边框、焦点、图标与弹窗；检查对比度。系统的减少动态效果偏好独立于明暗主题，适用时降低或关闭非必要动画。
- 根据产品支持矩阵核对目标浏览器和 Windows、macOS、Linux 等操作系统中的字体回退、键盘快捷键、触控/鼠标交互、滚动条与文件选择体验。依赖具体平台 API 时提供能力检测或适当退化；不按操作系统名称复制整套页面。

## 验证

按目标支持范围检查语言切换与回退、数字日期格式、长文案、组件库内置文案、系统主题变化、手动覆盖和减少动画偏好。跨平台问题以可复现设备、浏览器版本和操作路径记录；未实测平台不报告为已适配。
