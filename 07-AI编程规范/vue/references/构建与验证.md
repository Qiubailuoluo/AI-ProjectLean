# Vue 构建、配置与验证

适用范围：依赖、环境配置、构建产物、部署入口或前端测试变更。以项目现有包管理器、构建器、脚本及部署目标为准。

## 构建与环境

- 核对 Vue、Router、状态管理、组件库和构建器的实际版本与兼容关系；沿用锁文件和项目脚本。单项变更不自动升级整套前端依赖。
- 开发服务器代理仅说明本地开发请求路径；生产环境 API 地址、跨域、反向代理及静态资源路径需按实际部署另行核验。
- 浏览器可获取的构建变量和打包产物不得包含密钥。构建期变量变化通常需要重新构建；配置来源、模式和生效值按目标构建器核实。
- 静态资源基础路径、Router History 模式和实际托管服务的路由回退共同决定刷新及直接访问结果。版本发布还应核对缓存策略与旧页面引用新旧静态资源的兼容性。

仅为本机启动调整环境、代理或脚本时，读取[本地运行配置与提交隔离](../../common/references/本地运行配置与提交隔离.md)；个人覆盖与共享修复分别处理，不能因文件未提交就推定构建不会加载。

## 验证选择

- 组件与状态逻辑按风险选择单元或组件测试；路由、接口、登录和关键表单流程按需使用集成或浏览器验证。Mock 只证明被模拟边界内的前端行为。
- 分别记录类型检查、格式检查、构建、测试、预览和目标环境结果。构建成功不证明接口、权限或代理路径正确。
- 跨前后端改动核对请求与响应契约、错误语义、认证状态、上传完成及真实部署入口。仅依赖前端 Mock 或开发服务器代理不足以证明联调完成。

官方参考：[Vue 测试指南](https://vuejs.org/guide/scaling-up/testing.html)、[Vite 环境变量与模式](https://vite.dev/guide/env-and-mode)、[Vue Router History 模式](https://router.vuejs.org/guide/essentials/history-mode.html)。Vite 规则仅在项目实际使用 Vite 时适用。
