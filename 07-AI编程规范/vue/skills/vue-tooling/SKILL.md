# Vue 构建与验证

按当前决策需要核对项目版本、包管理器、锁文件、脚本、构建器、路由模式及目标环境。配置或代码修改时，读取[代码复用与注释](../../../common/references/代码复用与注释.md)；按需读取[构建与验证](../../references/构建与验证.md)。

涉及浏览器流程测试时读取[页面可操作性与自动化验证](../../references/页面可操作性与自动化验证.md)；涉及下载包、附件或发布产物体积时读取[资源发布与上传下载](../../../common/references/资源发布与上传下载.md)。

涉及项目根目录、环境文件位置、Docker/Compose 或部署目录调整时，读取[项目目录与部署边界](../../../common/references/项目目录与部署边界.md)。

生产代理或静态服务实际采用 Nginx，且本次涉及其配置时，组合 [Nginx Skill](../../../nginx/SKILL.md)；其他托管方式依据对应平台配置。依据项目实际命令验证受影响的构建与运行行为；分别报告静态检查、构建、测试和真实部署结果。
