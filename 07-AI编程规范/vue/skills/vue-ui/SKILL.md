# Vue 页面与组件

按当前决策需要核对现有组件、设计系统、页面调用方与项目 Vue 版本。实现代码修改时，读取[代码复用与注释](../../../common/references/代码复用与注释.md)；涉及组件、表单、字段展示、渲染或无障碍行为时，读取[页面与组件](../../references/页面与组件.md)。

涉及重复组件或样式、单文件职责混杂、流程持续堆叠时，读取[页面组织与复用](../../references/页面组织与复用.md)，在变更范围内评估抽取或局部重构。

涉及视觉设计、组件库选型、配色或动画时，读取[设计系统与交互](../../references/设计系统与交互.md)；涉及多语言、系统主题或跨操作系统交互时，读取[国际化与平台适配](../../references/国际化与平台适配.md)。

涉及接口加载或提交时组合 [vue-data](../vue-data/SKILL.md)；涉及页面进入条件时组合 [vue-navigation](../vue-navigation/SKILL.md)。依据受影响交互核对输入、加载、失败与成功状态；不从示例推定项目使用的组件库或代码风格。
