# 第四章：数据存储与访问
## 存储系统分工
### MySQL 保存业务记录
#### 订单、商品及约束与事务
#### 不把缓存命中当作可靠库存扣减
### Redis 提供键与数据结构能力
#### 商品缓存是可重建副本的一种用法
#### 缓存、计数与幂等占位不是同一问题
### MinIO 管理对象内容
#### Bucket 与 Key 定位图片或附件
#### MySQL 记录业务归属、状态和引用
### 其他系统按问题选择
#### 搜索、日志等能力可按需要扩展
#### 不因技术名词多就全部引入项目
## 关系建模与字段
### 主键、关联字段与外键
#### 主键标识记录，关联字段表达业务引用
#### 数据库外键与 Java 对象引用不是同一机制
### 订单主表与明细
#### 一笔订单可包含多条购买明细
#### 主表与明细各保留相应职责
### 历史交易快照
#### 保存成交名称、单价和数量
#### 不随商品当前价格重算历史订单
### 金额与约束
#### DECIMAL 与 BigDecimal 配合精度规则
#### 非空、默认、唯一和 CHECK 按业务语义设计
### 数据库约束与业务校验配合
#### 前端输入检查不替代后端和数据库保障
#### 默认值不自动成为正确业务值
## 索引查询路径
### B+ 树与页面
#### 分支导航、叶子有序，便于范围查找
#### 页面可能在内存，过一层不等于必读一次磁盘
### 聚簇索引与二级索引
#### 聚簇索引按主键组织行数据
#### 二级索引保存索引字段及行主键
### 回表方向
#### 先从二级索引取得主键
#### 再访问同一张表的聚簇记录，不是去另一张表
### 覆盖索引
#### 查询所需列可从索引取得时可减少回表
#### 是查询与索引的关系，不是独立树种
### 联合索引的顺序
#### 先按前列，再在相同前列值内按后列排序
#### WHERE 书写顺序不决定最左前缀
### 索引有读写代价
#### 索引占空间并增加写入维护成本
#### 不为零回表把所有响应字段塞进索引
## 慢查询定位与验证
### 找到真正执行的 SQL
#### 从慢日志与调用链对应 Mapper 或其他来源
#### 保存最终 SQL、实际参数与类型，不只复制 XML 模板
### 理解执行计划
#### key 有值仍可能扫描很多记录
#### Using index 通常指覆盖，filesort 不一定落盘
### 估计与实际不同
#### 普通 EXPLAIN 给出计划与估算
#### EXPLAIN ANALYZE 会实际执行支持的查询
### 不把所有慢请求归因于索引
#### 检查锁、连接等待、负载与数据分布
#### 先核对结果正确性，再做同条件前后比较
## 查询与分页
### 页码分页
#### LIMIT 20 OFFSET 20 表示第二页最多二十条
#### 深偏移通常仍需经过并跳过前面的结果
### 排序必须明确
#### 时间降序再按唯一 ID 降序
#### 只按时间会留下同一时刻的先后歧义
### 游标需要配合排序
#### 时间更早，或时间相同且 ID 更小
#### 只保存时间可能遗漏或重复同一时刻记录
### 前后端书签
#### 下一页带回后端生成的 nextCursor
#### 查二十一条时，以实际返回的第二十条生成游标
### 适用条件与变化边界
#### 任意跳页与连续加载需要不同取舍
#### 游标不自动形成跨请求数据库快照
## Redis 缓存读写
### Key、Value 与 TTL
#### Key 区分业务与必要的用户或租户范围
#### SET 配合 EX 写值及有效期，数值按场景选择
### 旁路缓存读取
#### 命中返回，未命中查数据库并按需填缓存
#### 不存在与 Redis 超时是不同状态
### 写后失效
#### 数据库成功提交后删除相关缓存
#### 事务方法最后一行 DEL 不等于提交后执行
### 并发旧值回填
#### 读到旧值的请求可能在删除后又填回旧缓存
#### TTL 不代表强一致，关键业务重新校验
### 可靠失效与降级
#### 必要时用持久化任务重试并监控积压
#### Redis 故障不能无限回源压垮数据库
### 穿透、击穿与雪崩
#### 不存在 ID、热点失效和集中失效需要不同应对
#### 空缓存、请求合并、打散有效期按条件选择
## MinIO 文件管理
### 对象位置与业务信息
#### Bucket 与 Key 不等于临时访问 URL
#### 数据库保存归属、用途、状态和业务引用
### 上传许可与确认
#### 后端生成唯一 Key，前端按许可上传
#### 上传完成通知需核对对象，不能直接相信客户端声明
### 校验与防覆盖
#### 元数据和 Content-Type 不证明内容真实
#### 预签名地址未必一次性，确认后仍要防止被再覆盖
### 授权下载
#### 先核对订单与文件权限，再转发或签短期地址
#### 私有附件不因页面要展示而全部公开
### 绑定、换图与回收
#### 新文件就绪再切换业务引用
#### 无引用清理要考虑宽限期与并发，删除失败可恢复
### 事务的剩余边界
#### 数据库回滚不自动删除已上传对象
#### 版本管理或对象保留可能影响物理清理
## 阅读与实践状态
### 基础阅读稿齐备，仍在学习
#### 查询与分页基础已有讨论
#### Redis 与 MinIO 为待通读和答疑材料
### 尚未进行真实验证
#### 未执行 SQL 性能、缓存并发或文件流转实验
#### 阅读导图不等于业务方案已验证
